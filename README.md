# Edge-Cloud ECLO Scheduler

Next.js + JavaScript + MongoDB Atlas simulation of priority-based edge-cloud scheduling with dynamic VM allocation.

## Algorithms
- Static Priority
- Dynamic Priority
- Integrated Priority
- Adaptive Integrated + Dynamic VM Allocation

## Run
```bash
npm install
```

Create `.env.local`:
```env
MONGODB_URI=your_mongodb_connection_string
```

Then:
```bash
npm run dev
```

Open http://localhost:3000
